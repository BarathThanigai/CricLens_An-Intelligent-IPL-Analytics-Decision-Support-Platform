# CricLens 🏏

## An Intelligent IPL Analytics & Decision Support Platform using R

> **From Every Ball to Every Insight.**

CricLens is an interactive IPL analytics and decision-support platform that transforms historical IPL data into meaningful statistical, visual, and predictive insights.

The core analytics engine is built using **R**, while a web application provides interactive access to the analytics. An **NVIDIA NIM-powered AI assistant** acts as an enhancement layer, allowing users to query the available analytics using natural language.

---

## Overview

IPL generates a large amount of data across:

- Matches
- Ball-by-ball deliveries
- Players
- Teams
- Venues
- Toss decisions
- Match outcomes
- Batting and bowling performances

However, extracting useful insights from this data often requires programming and statistical knowledge.

**CricLens solves this by providing a unified analytics platform where users can:**

- Explore IPL statistics interactively
- Analyze player and team performance
- Identify historical trends
- Compare players, teams, and venues
- Generate statistical insights
- Apply predictive models
- Visualize complex cricket data
- Query analytics using natural language

### Core Principle

> **R performs the analytics. AI makes those analytics easier to access.**

NVIDIA NIM does **not** perform the underlying statistics, machine learning, predictions, or visualizations. These are generated by the R analytics engine.

---

# Key Features

## Player Analytics

Analyze individual player performance using metrics such as:

- Runs
- Strike Rate
- Batting Average
- Boundaries
- Wickets
- Bowling Economy
- Season-wise Performance
- Venue-wise Performance

## Team Analytics

Analyze:

- Win Percentage
- Season Performance
- Batting Trends
- Bowling Trends
- Head-to-Head Records
- Toss Impact
- Chasing vs Defending Performance

## Statistical Analytics

CricLens applies statistical techniques to identify:

- Trends
- Distributions
- Correlations
- Performance patterns
- Player comparisons
- Team patterns
- Season-wise changes

## Predictive Analytics

Machine-learning models implemented in R can be used for:

- Match Outcome Prediction
- Score Estimation
- Player Performance Prediction

Models will be evaluated using appropriate validation techniques and performance metrics.

## Interactive Visualizations

The platform can provide:

- Line Charts
- Bar Charts
- Scatter Plots
- Heatmaps
- Radar Charts
- Player Comparison Charts
- Performance Trends
- KPI Cards

## AI Analytics Assistant

Users can ask questions in natural language.

Example:

> "Compare Kohli and Rohit at Wankhede."

The AI interprets the question and interacts with the analytics layer to return an understandable response.
